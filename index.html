Enterprise HR Data Integration & Identity Provisioning Platform

Azure Databricks · Dayforce HCM · MidPoint IDM · Cornerstone LMS · REST APIs · Unity Catalog

Designed and implemented an automated HR integration platform that replaced a fully manual 3-system handoff with a real-time, fault-tolerant data pipeline. The platform synchronizes employee lifecycle data — hires, updates, terminations — across Dayforce, MidPoint, and Cornerstone on the same day events occur, eliminating 15–20 hours of weekly manual data work and processing 3,000+ monthly employee events with zero manual touchpoints.

Azure Databricks PySpark Delta Lake REST APIs OAuth2 Unity Catalog ABAC/RBAC Python SQL Dayforce HCM MidPoint IDM Cornerstone LMS
Key Contributions
Medallion Architecture — Architected all 4 layers (Bronze → Silver → Core → Writeback) as Single Source of Truth for 5,000+ employee records across 3 enterprise systems.
Ingestion Framework — Built 3-notebook ingestion pipeline: XRef discovery, parallel employee detail extraction, and DLQ-based replay for failed records with watermark lineage tracking.
Failure Recovery — Developed Dead Letter Queue and replay framework with bounded retry cycles, reducing manual reprocessing effort by 80% and ensuring full data completeness.
PII Data Masking — Protected 20+ PII fields using Unity Catalog Governed Tags, ABAC policies, and custom masking functions achieving compliance-ready access controls across all platforms.
Identity Provisioning — Automated identity workflows linking Dayforce records, MidPoint GIDs, and Cornerstone accounts — streamlining onboarding and terminations on the same day.
Zero Manual Touchpoints — Replaced manual 3-system handoff with an automated pipeline processing 100+ daily and 3,000+ monthly employee events with zero manual intervention.
